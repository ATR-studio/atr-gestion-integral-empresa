☁️ Configurar Google Drive

Para sincronizar tus datos con Google Drive, necesitás tu Google Drive API Key y el ID de una carpeta donde guardar los datos.

El ID está en la URL de la carpeta de Drive
💡 Alternativa simple:
Sin API key, el sistema guarda todo en el navegador (localStorage). Podés exportar un JSON y subirlo a Drive manualmente desde Configuración > Datos.
